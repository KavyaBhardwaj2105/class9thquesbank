SECTION A — Multiple Choice Questions (15)

Q1. Which expression is a linear polynomial in x?

Correct Answer: 7x − 5. Its highest power of x is 1.

Q2. In the polynomial 9x − 13, what is the coefficient of x?

Correct Answer: 9. The number multiplying x is its coefficient.

Q3. How many terms does 5x − 8 have?

Correct Answer: 2. The terms are 5x and −8.

Q4. Which pair consists of like terms?

Correct Answer: −7x and 12x. Both contain x to the first power.

Q5. What is the constant term in 11x + 4?

Correct Answer: 4. It does not contain the variable.

Q6. What is the value of 6x − 7 when x = 3?

Correct Answer: 11. 6(3) − 7 = 18 − 7 = 11.

Q7. Which expression represents “five more than three times x”?

Correct Answer: 3x + 5.

Q8. Simplify: 8a + 5a − 3.

Correct Answer: 13a − 3. Like terms 8a and 5a combine to give 13a.

Q9. Which expression has exactly three terms?

Correct Answer: 4p + 6 − 2q.

Q10. Which of the following is equivalent to 12x − 9x + 4?

Correct Answer: 3x + 4.

Q11. If y = −2, what is the value of 4y + 9?

Correct Answer: 1. 4(−2) + 9 = −8 + 9 = 1.

Q12. Which expression represents the perimeter of a rectangle with length x + 3 cm and width 2 cm?

Correct Answer: 2x + 10. P = 2[(x + 3) + 2] = 2x + 10.

Q13. Which statement about 15 − 2m is correct?

Correct Answer: Its constant term is 15.

Q14. If 5x + k becomes 18 when x = 2, what is k?

Correct Answer: 8. 5(2) + k = 18, so k = 8.

Q15. Which expression is NOT a linear polynomial?

Correct Answer: 5x² + 2. Its highest power is 2, not 1.

SECTION B — True / False (10)

Q16. The expression 7x + 2 is a linear polynomial.

Correct Answer: True. The highest power of x is 1.

Q17. In 9p − 4, the number −4 is the coefficient of p.

Correct Answer: False. The coefficient is 9; −4 is the constant term.

Q18. 5a and −11a are like terms.

Correct Answer: True. Both have the same variable part a.

Q19. The polynomial 4x − 3 has three terms.

Correct Answer: False. It has two terms: 4x and −3.

Q20. In 12y, the coefficient of y is 12.

Correct Answer: True.

Q21. The expressions 3x and 3x² are like terms.

Correct Answer: False. Their powers are different.

Q22. The value of 2n + 5 for n = 4 is 13.

Correct Answer: True. 2(4) + 5 = 13.

Q23. 6x + 4x − 7 simplifies to 10x − 7.

Correct Answer: True.

Q24. A constant term must always be positive.

Correct Answer: False. A constant can be positive, negative or zero.

Q25. 2x + 3y is a linear polynomial in two variables.

Correct Answer: True. Each variable has power 1 and the total expression is linear.

SECTION C — Assertion & Reasoning (5)

Q26. Assertion (A): 7x − 4 is a linear polynomial.
Reason (R): The highest power of x in the expression is 1.

Correct Answer: A. Degree 1 is exactly why the polynomial is linear.

Q27. Assertion (A): 5x and 5x² are unlike terms.
Reason (R): Their variable parts have different powers.

Correct Answer: A.

Q28. Assertion (A): The constant term of 3y − 8 is −8.
Reason (R): A constant term contains no variable.

Correct Answer: A.

Q29. Assertion (A): 4x + 9x can be combined.
Reason (R): Both terms have x with the same power.

Correct Answer: A. They are like terms, so their coefficients can be added.

Q30. Assertion (A): 6x² + 2 is a linear polynomial.
Reason (R): The expression contains a variable with exponent 2.

Correct Answer: D. The reason is true, but power 2 means the polynomial is not linear.

SECTION D — Fill in the Blanks (5)

Q31. In 14x − 9, the coefficient of x is ______.

Correct Answer: 14.

Q32. The degree of the polynomial 8z + 3 is ______.

Correct Answer: 1.

Q33. When p = 5, the value of 3p − 2 is ______.

Correct Answer: 13.

Q34. The simplified form of 9a − 4a + 6 is ______.

Correct Answer: 5a + 6.

Q35. A polynomial containing only one term is called a ______.

Correct Answer: monomial.

Correct matching: A–1, B–2, C–3, D–4.

Q37. Match each polynomial with its coefficient of the variable.

A. 8m − 1
B. −3n + 7

Correct matching: A–8, B–−3, C–11, D–5.

Q38. Match each expression with its value for the given variable.

A. 2x + 1, x = 4
B. 3y − 2, y = 5
C. 5p, p = 3

Correct matching: A–9, B–13, C–15, D–7.

Q39. Match each verbal description with its algebraic expression.

A. 4 more than x
B. 4 times x
C. 4 less than x
D. x less than 4
Correct matching: A–x+4, B–4x, C–x−4, D–4−x.

B. 8a − 6a + 5

SECTION F — Drag & Drop Style Questions (5)

Q41. Drag/select the expression that is a linear polynomial.

Correct Answer: 9x − 4.

Q42. Move/select the pair of like terms.

Correct Answer: −9p and 2p.

Q43. Select the simplified form to place with 5b + 7b − 2.

Correct Answer: 12b − 2.

Q44. Sort the following by selecting the expression with exactly two unlike terms.

Correct Answer: 5m + 7n. m and n are different variable parts.

Q45. Select the expression that represents the total of x, 3x and 5.

Correct Answer: 4x + 5. x + 3x + 5 = 4x + 5.

SECTION G — HOTS / Higher Order Thinking (10)

Q46. A number is represented by n. Another number is 7 greater than it. What is the sum of the two numbers in simplified form?

Correct Answer: 2n + 7. The numbers are n and n+7, so their sum is 2n+7.

Q47. Riya simplifies 6x + 4 − 2x + 9 as 4x + 13. Aman gets 4x − 5. Who is correct and why?

Correct Answer: Riya. 6x−2x = 4x and 4+9 = 13.

Q48. The perimeter of a square is represented by 4x + 12 cm. Find the side length in terms of x.

Correct Answer: x + 3. A square has four equal sides, so divide 4x+12 by 4.

Q49. Two expressions are A = 5x + 8 and B = 3x + 14. For which value of x are they equal?

Correct Answer: 3. 5x + 8 = 3x + 14 gives 2x = 6, so x = 3.

Q50. A shop charges ₹20 as a fixed packing fee and ₹35 for each notebook. Which expression gives the total cost of n notebooks?

Correct Answer: 35n + 20. ₹35 is charged for each notebook and ₹20 is fixed.

Q51. If 3x + 5 = 20, what is the value of x?

Correct Answer: 5. 3x = 15, therefore x = 5.

Q52. The expression 2x + 3y + 4 is changed by replacing x with 5 and y with 2. What value is obtained?

Correct Answer: 20. 2(5)+3(2)+4 = 10+6+4 = 20.

Q53. A rectangle has length 3x + 2 and width x + 4. Find its perimeter.

Correct Answer: 8x + 12. P = 2[(3x+2)+(x+4)] = 8x+12.

Q54. A student says, “3x + 4 and 4 + 3x are different polynomials because their terms are written in a different order.” Evaluate the statement.

Correct Answer: The student is incorrect. Addition is commutative, so 3x+4 = 4+3x.

Q55. Find the value of k if the expression 7x + k has value 30 when x = 4.

Correct Answer: 2. 7(4)+k=30, so 28+k=30 and k=2.
