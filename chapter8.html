Section A — Multiple Choice Questions

Q1. What is the next term in the sequence 4, 9, 14, 19, ___?

✓ Correct Answer: 24. Each term increases by 5.

Q2. Which rule generates the sequence 3, 6, 12, 24, 48?

✓ Correct Answer: Multiply by 2 each time.

Q3. Find the missing term: 7, 11, 15, ___, 23.

✓ Correct Answer: 19. The common difference is 4.

Q4. Which number comes next: 2, 5, 10, 17, 26, ___?

✓ Correct Answer: 37. The differences are 3, 5, 7, 9, so the next difference is 11.

Q5. What is the 10th term of the sequence 5, 8, 11, 14, ...?

✓ Correct Answer: 32. Starting from 5, add 3 nine times: 5 + 27 = 32.

Q6. Which sequence has a constant difference?

✓ Correct Answer: 11, 15, 19, 23. The difference is always 4.

Q7. A pattern has 6 dots in Figure 1, 10 dots in Figure 2 and 14 dots in Figure 3. How many dots will Figure 8 have?

✓ Correct Answer: 34. The pattern increases by 4, so Figure 8 = 6 + 7×4 = 34.

Q8. What is the next term in 81, 27, 9, 3, ___?

✓ Correct Answer: 1. Each term is divided by 3.

Q9. The sequence 12, 17, 22, 27, ... follows which rule?

✓ Correct Answer: Add 5.

Q10. Which term of the sequence 6, 10, 14, 18, ... is 42?

✓ Correct Answer: 10th. 6 + 9×4 = 42.

Q11. What is the next number in 1, 4, 9, 16, 25, ___?

✓ Correct Answer: 36. These are the squares of 1, 2, 3, 4, 5, 6.

Q12. A sequence begins 50, 45, 40, 35, ... What is its 7th term?

✓ Correct Answer: 20. Subtract 5 six times: 50 − 30 = 20.

Q13. Which number replaces the box? 4, 8, 16, □, 64.

✓ Correct Answer: 32. Each term is twice the previous term.

Q14. The first four terms of a pattern are 100, 90, 80, 70. Which expression describes the next term?

✓ Correct Answer: 70 − 10 = 60.

Q15. A staircase pattern uses 3 blocks in Figure 1, 6 in Figure 2, 9 in Figure 3 and so on. How many blocks are needed for Figure 12?

✓ Correct Answer: 36. Each figure uses 3 more blocks, so Figure 12 has 12 × 3 = 36 blocks.

Section B — True / False

Q16. In the sequence 8, 13, 18, 23, the common difference is 5.

✓ Correct Answer: True.

Q17. The sequence 2, 6, 10, 14 has a common difference of 3.

✓ Correct Answer: False. The common difference is 4.

Q18. In the sequence 20, 17, 14, 11, each term is obtained by subtracting 3.

✓ Correct Answer: True.

Q19. The sequence 1, 2, 4, 8, 16 is formed by adding 2 each time.

✓ Correct Answer: False. Each term is multiplied by 2.

Q20. The next term after 15, 20, 25, 30 is 35.

✓ Correct Answer: True.

Q21. Every sequence must have a constant difference.

✓ Correct Answer: False. Some sequences have changing differences or other rules.

Q22. The first five square numbers are 1, 4, 9, 16 and 25.

✓ Correct Answer: True.

Q23. In 30, 25, 20, 15, the sequence is increasing.

✓ Correct Answer: False. The sequence is decreasing.

Q24. If a pattern increases by 7, then the difference between consecutive terms is 7.

✓ Correct Answer: True.

Q25. In the sequence 5, 10, 20, 40, the next term is 45.

✓ Correct Answer: False. The next term is 80 because the terms are doubled.

Q26. Assertion: The sequence 12, 16, 20, 24 has a common difference of 4.
Reason: 16 − 12 = 4 and the same difference occurs between consecutive terms.

✓ Correct Answer: A. Both statements are true and the reason explains the common difference.

Q27. Assertion: The next term of 3, 6, 12, 24 is 48.
Reason: Every term is obtained by multiplying the previous term by 2.

✓ Correct Answer: A.

Q28. Assertion: The sequence 9, 14, 19, 24 is decreasing.
Reason: Its common difference is 5.

✓ Correct Answer: C. The assertion is false because the sequence is increasing; the reason is true.

Q29. Assertion: In 40, 35, 30, 25, the next term is 20.
Reason: 40 − 5 = 35.

✓ Correct Answer: B. Both are true, but the reason gives only the first step and does not fully establish the next term by itself.

Q30. Assertion: The sequence 2, 5, 10, 17 can be continued by adding consecutive odd numbers.
Reason: The differences are 3, 5 and 7.

✓ Correct Answer: A. The differences are consecutive odd numbers: 3, 5, 7.

Section G — HOTS / Higher Order Thinking

Q46. A sequence begins 11, 17, 23, 29, ... Which term is 71?

✓ Correct Answer: 11th. From 11 to 71 is an increase of 60. Since each step adds 6, there are 10 steps, so it is the 11th term.

Q48. A sequence follows the rule “start with 7 and add 4 each time.” What is the sum of the 3rd and 8th terms?

✓ Correct Answer: 50. The 3rd term is 15 and the 8th term is 35. 15 + 35 = 50.

Q49. A pattern has 2 tiles in Figure 1, 5 in Figure 2, 10 in Figure 3 and 17 in Figure 4. If the differences continue as 3, 5, 7, 9, what will Figure 5 contain?

✓ Correct Answer: 26. Figure 5 = 17 + 9 = 26.

Q50. Riya writes 100, 95, 90, 85, ... A friend says the 15th term is 35. Is the friend correct?

✓ Correct Answer: The friend is not correct. The 15th term is 100 − 14×5 = 30.

Q51. A sequence has first term 8 and common difference 7. Which term is 71?

✓ Correct Answer: 10th. 8 + 9×7 = 71.

Q52. A pattern begins 1, 4, 9, 16, 25. Another student claims the next term is 30 because 25 + 5 = 30. What is the correct next term and why?

✓ Correct Answer: 36. The terms are 1², 2², 3², 4², 5², so the next term is 6² = 36.

Q53. A bus-stop display shows the sequence 6, 12, 18, 24, ... If the pattern continues, what is the total of the 7th and 9th terms?

✓ Correct Answer: 96. The 7th term is 42 and the 9th term is 54. Their sum is 96.

Q54. A number pattern starts at 3. Each new term is obtained by multiplying by 2 and then adding 1. What are the first five terms?

✓ Correct Answer: 3, 7, 15, 31, 63. Starting with 3: 3×2+1=7, 7×2+1=15, and so on.

Q55. Two students describe the sequence 10, 15, 20, 25, ... Student A says the 20th term is 105. Student B says it is 110. Who is correct?

✓ Correct Answer: Student A. The 20th term is 10 + 19×5 = 105.
