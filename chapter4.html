Half-Yearly Examination Question Bank & Revision Test

SECTION A — Multiple Choice Questions (15)

Q1. Which identity represents the square of a sum?

Correct Answer: a² + 2ab + b². This is the identity (a+b)².

Q2. The expansion of (x + 5)² is:

Correct Answer: x² + 10x + 25.

Q3. Which expression is equivalent to (p − 4)²?

Correct Answer: p² − 8p + 16.

Q4. What is the middle term in the expansion of (y + 7)²?

Correct Answer: 14y. The middle term is 2 × y × 7.

Q5. Which identity can be used to simplify (m + n)(m − n)?

Correct Answer: a² − b².

Q6. Simplify: (x + 3)(x − 3).

Correct Answer: x² − 9.

Q7. What is the value of 51² using an identity?

Correct Answer: 2,601. 51² = (50+1)² = 2500+100+1.

Q8. Which expression equals a² − 2ab + b²?

Correct Answer: (a−b)².

Q9. Find the missing term: (x + 4)² = x² + ______ + 16.

Correct Answer: 8x.

Q10. Which pair of expressions are always equal?

Correct Answer: (a+b)² and a²+2ab+b².

Q11. What is (20 + 3)²?

Correct Answer: 529.

Q12. Which expression gives the product of (r + 6) and (r − 6)?

Correct Answer: r² − 36.

Q13. If a = 8 and b = 2, what is the value of (a − b)²?

Correct Answer: 36. (8−2)² = 6² = 36.

Q14. Which term makes x² + 12x + ______ a perfect square?

Correct Answer: 36. x²+12x+36 = (x+6)².

Q15. What is 99²?

Correct Answer: 9,801. (100−1)² = 10000−200+1.

SECTION B — True / False (10)

Q16. (a+b)² = a² + 2ab + b².

Correct Answer: True.

Q17. (a−b)² = a² − b².

Correct Answer: False. (a−b)² = a²−2ab+b².

Q18. (p+q)(p−q) = p²−q².

Correct Answer: True.

Q19. The middle term of (x+9)² is 18x.

Correct Answer: True.

Q20. 25² can be calculated using (20+5)².

Correct Answer: True.

Q21. (m+n)² contains the term 2mn.

Correct Answer: True.

Q22. (x−5)² = x²−10x+25.

Correct Answer: True.

Q23. (7+2)(7−2) = 45.

Correct Answer: True. 49−4 = 45.

Q24. The identity (a+b)² can be used to calculate 48² quickly.

Correct Answer: True. 48 = 50−2, so (50−2)² can be used.

Q25. In (x+3)², the constant term is 6.

Correct Answer: False. The constant term is 9.

SECTION C — Assertion & Reasoning (5)

Q26. Assertion (A): (x+5)² = x²+10x+25.
Reason (R): The square of a sum is a²+2ab+b².

Correct Answer: A.

Q27. Assertion (A): (y−4)² has a negative middle term.
Reason (R): The identity (a−b)² contains −2ab.

Correct Answer: A.

Q28. Assertion (A): (p+q)(p−q) has no pq term after simplification.
Reason (R): The two cross-products +pq and −pq cancel each other.

Correct Answer: A.

Q29. Assertion (A): 49² can be found conveniently using (50−1)².
Reason (R): 49 is one less than 50.

Correct Answer: A.

Q30. Assertion (A): (a+b)² = a²+b².
Reason (R): The middle term 2ab must also be included.

Correct Answer: D. The correct expansion contains 2ab.

SECTION D — Fill in the Blanks (5)

Q31. (x+7)² = x² + 14x + ______.

Correct Answer: 49.

Q32. (z−6)² = z² − 12z + ______.

Correct Answer: 36.

Q33. (t+9)(t−9) = t² − ______.

Correct Answer: 81.

Q34. The middle term of (a+11)² is ______.

Correct Answer: 22a.

Q35. 72² can be written as (70+2)², where the value of the middle term is ______.

Correct Answer: 280. Middle term = 2×70×2.

SECTION E — Match the Following (5)

Q36. Match each identity with its correct expansion.

A. (a+b)²
B. (a−b)²
C. (a+b)(a−b)
D. (a+b)²−2ab
Correct matching: A–a²+2ab+b², B–a²−2ab+b², C–a²−b², D–a²+b².

Q37. Match each numerical square with its value.

A. 21²
B. 23²
C. 25²
D. 27²
Correct matching: 21²–441, 23²–529, 25²–625, 27²–729.

Q38. Match each expression with its simplified form.

A. (x+2)²
B. (y−3)²
C. (p+5)(p−5)
D. (z+6)²
Correct matching: A–x²+4x+4, B–y²−6y+9, C–p²−25, D–z²+12z+36.

Q39. Match each number with the identity form used to calculate its square.

A. 48²
B. 52²
C. 99²
D. 103²
Correct matching: A–(50−2)², B–(50+2)², C–(100−1)², D–(100+3)².

Q40. Match each missing constant with the perfect-square expression.

A. x²+8x+____
B. y²+10y+____
C. p²−14p+____
D. z²+18z+____
Correct matching: A–16, B–25, C–49, D–81.

SECTION F — Drag & Drop Style Questions (5)

Q41. Drag/select the correct expansion for (n+6)².

Correct Answer: n²+12n+36.

Q42. Place the correct result with (k+8)(k−8).

Correct Answer: k²−64.

Q43. Select the expression that is a perfect square.

Correct Answer: x²+10x+25 = (x+5)².

Q44. Select the correct identity-based value of 97².

Correct Answer: 9,409. (100−3)² = 10000−600+9.

Q45. Select the missing middle term: (2x+3)² = 4x² + ______ + 9.

Correct Answer: 12x. 2ab = 2×2x×3 = 12x.

SECTION G — HOTS / Higher Order Thinking (10)

Q46. Without directly multiplying, find 102² using an algebraic identity.

Correct Answer: 10,404. (100+2)² = 10000+400+4.

Q47. A student writes (x−7)² = x²−49. Identify the missing part of the student's expansion.

Correct Answer: −14x and +49. (x−7)² = x²−14x+49.

Q48. If a+b = 15 and ab = 26, find a²+b².

Correct Answer: 173. (a+b)² = a²+2ab+b², so 225 = a²+b²+52.

Q49. If a−b = 9 and ab = 10, find a²+b².

Correct Answer: 101. (a−b)² = a²−2ab+b², so 81 = a²+b²−20.

Q50. Find 49 × 51 using the difference of squares identity.

Correct Answer: 2,499. (50−1)(50+1) = 50²−1² = 2,499.

Q51. Find the value of 98² − 2² without calculating the two squares separately.

Correct Answer: 9,600. 98²−2² = (98−2)(98+2)=96×100.

Q52. A square has side length (x+4) cm. Which expression represents its area?

Correct Answer: x²+8x+16. Area = (x+4)².

Q53. Two square-shaped tiles have side lengths 30 cm and 2 cm. Using an identity, find the difference between their areas.

Correct Answer: 896 cm². 30²−2² = (30−2)(30+2)=28×32=896.

Q54. If x+3 = 11, determine x²+6x+9 without first finding x² separately.

Correct Answer: 121. x²+6x+9 = (x+3)² = 11².

Q55. If x−5 = 12, find x²−10x+25 without finding x first.

Correct Answer: 144. x²−10x+25 = (x−5)² = 12².
